Trust Card Check API

Integrate automated link safety verification, brand impersonation detection, and certificate validation into email gateways, chat bots, and security pipelines.

POST /api/v1/analyze

Submits a link for local threat intelligence matching, URL lookalike analysis, and optional live certificate and web safety auditing.

1. Local-Only Check (Zero Outbound Network)

curl -s -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/login",
    "mode": "local",
    "context_flags": ["credential_request"]
  }'

2. Consented Live Website Scan

curl -s -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/",
    "mode": "full_scan",
    "consent": true,
    "ct_rdap_consent": true
  }'

Request Body Schema

FieldTypeRequiredDescription
urlstringYesHTTP or HTTPS URL to verify (8–2048 characters).
modestringYes"local" for offline analysis or "full_scan" for live scanning.
consentbooleanConditionalRequired when mode="full_scan". Authorizes outbound connection.
ct_rdap_consentbooleanNoOptional consent to query CT logs (crt.sh) and domain age (rdap.org).
context_flagsarrayNoCues detected by client ("urgency", "credential_request", "payment_request", "personal_data_request").

GET /api/v1/admin/export

Exports approved local threat reports signed with HMAC-SHA256 for peer sharing between Trust Card instances. Requires Admin Basic Authentication and configured SHARING_KEY.

curl -s -u "AD:Aritra@1234" http://127.0.0.1:8000/api/v1/admin/export

POST /api/v1/admin/import

Ingests signed threat reports from a peer Trust Card node into the local unverified review queue. Enforces HMAC-SHA256 signature verification and a 1 MiB size limit.
