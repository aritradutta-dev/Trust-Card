📖 How to read this card: Understanding pillars, coverage, and verdicts

1. Why "No warning found" is never "Safe"

Attackers register new domains daily, use legitimate cloud hosting, and obtain valid certificates. A clean result means our automated checks detected no known threat signatures across the checked scope — it is never an endorsement or guarantee of safety. Always visit official services directly.

2. The 7 Security Pillars

Trust Card unifies 7 security dimensions: Threat Intelligence, URL & Impersonation, Page Content, Certificate & Trust, Web Security, Community Intelligence, and Message Context. Pillars clearly display status badges: Alert, Attention, Clear, or Not checked.

3. Local vs. Full Scan Coverage

Local-only check: Zero outbound network connections. Evaluates cached threat intelligence, brand lookalikes, URL structure, and community reports.

Full live scan: Consented connection with IP pinning. Performs deep TLS validation, checks for weak cryptographic key generation, detects credential-harvesting forms, and audits HTTP security headers.

4. Indicator Score vs. Authoritative Verdict

The 0–100 indicator score provides transparent risk ranking across completed checks. However, deterministic verdict rules remain authoritative: technical findings like missing headers or certificate expiration will never turn a link into a "Known threat".

What the scanner will do
