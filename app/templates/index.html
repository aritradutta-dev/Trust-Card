What the scanner will do

  • Make one read-only GET request to the URL above using its HTTP or HTTPS scheme on port 80 or 443.
  • If it redirects, make up to five more GET requests to public destinations — six GET requests total.
  • Finish within 20 seconds. Read response headers and up to 2 MiB of HTML for static password-form checks.

What it will not do

  • Try alternate schemes, www, or guessed URL variants.
  • Run page scripts, submit forms, or send the URL to reputation providers.
